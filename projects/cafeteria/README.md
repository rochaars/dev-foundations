# Projeto Cafeteria

Projeto utilizado para prática de desenvolvimento Front-end.

## Contexto

A estrutura visual deste projeto foi desenvolvida anteriormente durante os estudos de HTML e CSS.

Após iniciar os estudos de JavaScript, o projeto foi retomado para aplicar conceitos da linguagem em uma página já existente, transformando elementos originalmente estáticos em funcionalidades interativas.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Conceitos de JavaScript praticados

- Variáveis
- Objetos
- Arrays
- `forEach()`
- `push()`
- `length`
- `getElementById()`
- `querySelector()`
- `querySelectorAll()`
- `closest()`
- `textContent`
- `addEventListener()`
- `preventDefault()`
- Manipulação do DOM
- `createElement()`

## Funcionalidades implementadas até o momento

- Identificação do produto clicado
- Captura dinâmica do nome e preço do produto
- Criação de objetos representando os produtos
- Armazenamento dos produtos em um array de carrinho
- Contador automático de itens do carrinho
- Percurso dos produtos utilizando `forEach()`
- Início da renderização dos produtos adicionados ao carrinho

## Status

🚧 Projeto em desenvolvimento.

Este projeto continuará recebendo novas funcionalidades conforme o avanço dos estudos de JavaScript.
